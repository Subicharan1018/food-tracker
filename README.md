# Kinetik — Fitness & Nutrition Tracker

A standalone, native mobile health and nutrition tracker built with Flutter, matching the functional depth of HealthifyMe with an original dark obsidian design system and zero server maintenance, backed by Google Cloud Firestore.

## Features
- **Rapid Food Logging (<15s flow)**: Search-first Indian food database pre-seeded with ICMR-NIN staples, portion multipliers, and custom food entry.
- **Hero Calorie Ring & Macro Quadrants**: Consumed, target, remaining, and workout offsets.
- **Macro Source Attribution**: Detailed breakdown of where your protein and carbs originated across the day or individual meals.
- **Dual Workout Architecture**: 50+ MET activity library + set-by-set recomp split workout logger.
- **Habit & Adherence Engine**: Hydration tracking, streaks, 7-day weight trend, and rule-based calorie/macro adjustment recommendations.
- **Personal Recipe Box**: Tamil Nadu high-protein dry-pack and curry recipes from `refeerece.html` with 1-tap logging.
- **Google Cloud Firestore Sync**: Direct REST sync to Google Cloud without running self-hosted servers.
